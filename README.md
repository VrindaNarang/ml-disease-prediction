# FemHealth - Smart Care for Her | 2024

A predictive analytics platform built to assess women’s risk of common diseases such as PCOS, thyroid disorders, and heart disease using machine learning. FemHealth provides personalized health scores based on individual risk profiles and medical data, enabling early intervention and proactive health management through data-driven insights.

---

## Features

- **Risk Assessment:** Uses ML models to evaluate the risk of PCOS, thyroid disorders, heart disease, and more.
- **Personalized Health Scores:** Generates a composite health score tailored to the user's unique medical and lifestyle data.
- **Early Intervention:** Provides actionable insights to support timely healthcare decisions.
- **Data-driven Insights:** Leverages medical data to empower proactive health management for women.

---

## Technologies Used

- **Backend:** Flask (Python web framework)  
- **Machine Learning:** Scikit-Learn (ML models for risk prediction)  
- **Frontend:** HTML, CSS, JavaScript (Responsive UI)  
- **Other:** Data processing and visualization tools integrated for delivering seamless user experience
